WBO Reference

Battle and match quick guide

1on1 Battle

Each blader selects one Bey and uses it for the full match.

3on3 Battle

Each blader uses an ordered deck of 3 Beys. After the 3rd Bey, both players may reorder in secret.

Counter Battle

Players reveal decks. After each battle, the previous battle loser calls rematch or counter.

Match Types

4-point, 5-point, and 7-point matches end when one blader wins one set at the selected point target.

Finish Points

Spin finishes score 1. Burst and over finishes score 2. Xtreme finishes score 3.

Optional Finishes

Own finish scores 1 when enabled. Out-of-bounds finish scores 1 or 2 as set by the organizer.
